# Analisis_Geoespacial
Repositorio proyecto del curso Análisis geoespacial
Este proyecto se propone como aplicar funciones del analisis geoespacial para la caracterizacion por movimientos en masa de una cuenca de la cordillera occidental.
Se buscara aplicar metodos de machine learning para clasificar zonas de susceptibilidad basado en un inventario de puntos y variables geoespaciales en formato raster.
